About This Workshop

This hands-on course teaches modern web standards and accessibility-first web design practices.

Core Concepts Covered

Document Hierarchy

Using a single <h1> per page and nesting <h2> through <h6> elements logically without skipping levels.

Accessible Forms

Pairing every input field with an explicit <label> element to support screen reader users.

Instructor Note

Remember to test all your HTML files using the W3C Markup Validator before submitting your final project.
